# 🎓 Student Management System

A modern and responsive **Student Management System** designed to simplify student record management, department administration, academic information, and administrative activities through a clean web interface.

The system includes **authentication, student management, department management, dashboard analytics, AI-powered assistance, password recovery, OTP verification, activity tracking, notifications, and enhanced security features.**

---

## 🚀 Features

### 🔐 Authentication & Security

* User login and authentication
* Admin and Staff roles
* Password strength indicator
* Forgot password workflow
* OTP verification interface
* Two-factor authentication (2FA) option
* Security indicators
* Activity log
* Rate-limit notification interface

### 👨‍🎓 Student Management

* Add new students
* View student records
* Update student information
* Delete student records
* Search students
* Filter student records
* Student status management
* Department-wise student information
* Academic information including CGPA
* Student profile information

### 🏫 Department Management

* Manage departments
* Department codes
* Department-wise student count
* Support for multiple engineering departments

### 📊 Dashboard

* Student statistics
* Department information
* Academic insights
* CGPA visualization
* Notifications
* Recent activities
* Responsive dashboard interface

### 🤖 AI Features

* AI assistant/chat interface
* Quick AI prompts
* AI-generated insights
* Interactive AI chat panel
* AI-focused dashboard components

### 🎨 UI/UX

* Modern professional design
* Responsive layout
* Mobile-friendly interface
* Clean navigation
* Interactive tables
* Search and filtering
* Toast notifications
* Loading states and skeleton loaders

## 👥 User Roles

### Admin

The administrator can manage student and department information and access administrative functionality.

### Staff

Staff users can access the student management functionality according to their assigned permissions.

The application includes separate Admin and Staff user roles in its current implementation.
